# SQL Business Reports & Queries

Este repositório reúne exemplos práticos de consultas SQL avançadas voltadas para extração de dados e inteligência de negócios (Business Intelligence).

## 📊 O que o projeto contém?
- **DDL:** Criação estruturada de tabelas relacionais (`clientes` e `pedidos`).
- **Agregações & JOINs:** Relacionamento de tabelas para cálculo de faturamento por cliente.
- **Subqueries:** Filtros avançados baseados em médias calculadas dinamicamente.
- **Filtros Condicionais:** Utilização de `GROUP BY`, `HAVING` e ordenação por desempenho.
